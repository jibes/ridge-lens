TinySkyNet sky segmentation model (public/models/skynet.json, skynet.bin)

Source:   https://github.com/kisakutanaka/SkySegmentation
File:     models/tinyskynet_skyseg_256.onnx, converted with scripts/export-skynet.py
Model:    49k-parameter depthwise-separable UNet, input 256x256 RGB, output 128x128 sky logits
Training: distilled in that repository from SkySeg (U-2-Net, MIT,
          https://huggingface.co/JianyuanWang/skyseg) on 3,901 Open Images V7 photos
          (CC BY 2.0)
License:  MIT for weights and code according to models/README.md of the source
          repository. (Its top-level LICENSE file still notes Apache-2.0 for the
          bundled models, which refers to an earlier PP-MobileSeg model; both licenses
          are compatible with the GPL-3.0 of Ridge Lens.)
